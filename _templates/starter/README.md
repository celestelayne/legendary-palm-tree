# Starter Template

Paste this boilerplate directly into their editor or feed it to an LLM coding agent as their structural scaffold. It includes built-in hooks for window geometry, cursor velocity, and optional ambient mic volume, plus a clean requestAnimationFrame physics loop.

## Sample Vibe-Coding Prompts

1. **Window-as-Room:** "Modify this starter so the browser window acts as a physical container with gravity. When I drag the browser window rapidly across my monitor, the suspended shapes slam against the viewport walls and cast distorted shadows."
2. **Acoustic Dust:** "Remove the pendulum and replace it with 400 weightless paper fragments. When the room is silent, they settle along the bottom edge of the window; when my microphone picks up speech or footsteps, they swirl upward like dust in a sunbeam."
3. **Impatient Architecture:** "Build a floor plan drawing that slowly drafts itself line-by-line only while my mouse is completely still (idleFrames > 60). Every time I touch the mouse, the walls tremble and erase slightly."
